# 小又的打砖块游戏

给 6–9 岁孩子玩的英语单词学习小游戏：经典打砖块 + 单词匹配。

屏幕顶部显示一个中文目标（例如「书店」），孩子移动底部滑块接球，用小球击中写着对应英文单词（bookshop）的砖块才能消除得分。单词砖按词性用不同颜色区分，击中正确砖会朗读单词。

整个游戏只用 HTML + CSS + JavaScript + Canvas，**没有任何外部库、图片、音频文件或网络请求**，可以直接离线玩。

---

## 一、如何打开

1. 找到 `word-breaker` 文件夹里的 `index.html`。
2. **双击 `index.html`**，用 Chrome 或 Edge 打开即可。
3. 不需要安装软件、不需要启动服务器、不需要联网。

第一次进入会先看到开始页：

- 选择 Unit 1～6；
- 可打开「慢速模式」（小球速度降低约 30%，适合低龄孩子）；
- 点「开始游戏」后先看 8 秒预习闪卡，然后开始玩；
- 有历史错词后，可以点「错词复习」进入错词关。

> 建议使用最新版 Chrome 或 Edge。手机、平板也可以用，支持横屏和竖屏。

## 二、基本玩法

- 鼠标拖动、手指拖动或键盘 `←` `→` 移动滑块。
- 点击画布、轻触画布或按空格发球。
- 先看画布顶部的中文目标和 emoji，再引导小球击中对应的英文单词砖。
- 目标只会从最外层、小球能打到的砖块中随机选择；如果某个目标被其他砖块完全围住（小球不可能打到），系统会自动换一个可达的目标并更新顶部提示。切换横屏/竖屏后也会重新检查。
- 击中正确砖：砖块消除、加分、朗读单词，并自动换下一个目标。
- 击中错误砖：砖块温和地闪一下红色，不消除、不扣分、不扣命，但连击会清零。
- 漏球扣 1 条命；每关 3 条命，命用完可以重玩本关。
- 连续击中正确砖会积累连击；连击 ≥ 3 时小球会加速约 10%，并出现更明显的粒子和光环。
- 过关或失败后都会先复习本关单词，再显示得分和正确率。


## 四、如何修改词库

打开 `js/words-data.js`，按下面的格式增删单词，保存后刷新浏览器即可生效，不需要改其他代码。

```js
const WORD_DATA = {
  unit1: {
    unit: 1,
    title: "Unit 1 · 运动与时间",
    words: [
      { word: "jump", zh: "跳", pos: "verb", emoji: "🦘", key: true },
      { word: "rope", zh: "绳", pos: "noun", emoji: "🪢" }
    ]
  },
  // unit2 ~ unit6 同结构
};
```

单词字段：

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| `word` | 必填 | 英文单词或短语 |
| `zh` | 必填 | 中文意思，会显示在目标卡片上 |
| `pos` | 必填 | 词性，只能填 `noun` / `verb` / `adj` / `other` |
| `emoji` | 可选 | 表情，没有就填空字符串 `""` |
| `key` | 可选 | 填 `true` 表示核心词，单词超过 18 个时优先选它上砖 |

砖块颜色由 `pos` 决定：

- `noun` 名词 → 蓝色
- `verb` 动词 → 橙色
- `adj` 形容词 → 绿色
- `other` 其他 → 灰色

注意事项：

- 每关最多铺 **18 块砖**。单词超过 18 个时，每次开局优先保留 `key: true` 的核心词，其余随机补足；多玩几次可以覆盖全部单词。
- 单词少于 18 个时按实际数量铺砖，最少建议 4 个。
- 中英文都可以用，但单词本身建议保持英文，否则朗读和认读效果不好。
- `word` 里可以带空格（如 `be good at`、`sports centre`），砖块会自动尝试拆成两行。
- 不同 Unit 可以有相同的英文单词（如 Unit 1 和 Unit 2 都有 `play`），错词统计会按 Unit 分开记录。
- 如果只修改了词库但页面没变化，请强制刷新（`Ctrl + F5`）或检查文件是否保存成功。

## 五、如何调整难度

打开 `js/main.js`，文件顶部有一个 `CONFIG` 对象，直接改数字即可。常用参数：

| 参数 | 默认值 | 作用 |
| --- | --- | --- |
| `START_LIVES` | `3` | 每关初始生命数 |
| `BALL_SPEED` | `430` | 小球基础速度（越大越快） |
| `SLOW_MODE_FACTOR` | `0.7` | 慢速模式速度倍率（0.7 ≈ 降低 30%） |
| `PADDLE_KEYBOARD_SPEED` | `760` | 键盘移动滑块的速度 |
| `PADDLE_HIT_PAD` | `18` | 滑块左右额外判定宽度，越大越容易接球 |
| `MAX_BRICKS` | `18` | 每关最多砖块数 |
| `PREVIEW_SECONDS` | `8` | 每关开始前预习闪卡的秒数 |
| `REVIEW_STEP_MS` | `1400` | 复习闪卡每个单词停留的毫秒数 |
| `REVIEW_MIN_WORDS` | `4` | 至少多少个错词才能进入错词复习 |
| `BRICK_SCORE` | `10` | 击中一块目标砖的基础得分 |
| `COMBO_SCORE_STEP` | `2` | 连击每多 1 次额外加的分 |
| `COMBO_SCORE_MAX` | `20` | 连击加分上限 |
| `COMBO_SPEED_THRESHOLD` | `3` | 连击达到多少次开始加速 |
| `COMBO_SPEED_BONUS` | `0.1` | 连击加速幅度（0.1 ≈ 提升 10%） |
| `PARTICLE_COUNT` | `12` | 每次击中的粒子数量（低配设备可调小） |

例如想让孩子更容易上手：

```js
START_LIVES: 5,
BALL_SPEED: 360,
SLOW_MODE_FACTOR: 0.6,
```

改完后保存并刷新页面即可。

## 六、声音与单词发音

- 击中正确、击中错误、过关三种音效都用 Web Audio API 现场合成，不依赖音频文件。
- 英文单词用浏览器自带的 `speechSynthesis` 朗读，优先选择美式/英式英文语音，语速约 0.85。
- 浏览器要求先有一次用户点击或按键才能播放声音，所以请在开始页点按钮、或先点一下画布。
- 如果电脑没有安装英文语音，游戏仍然正常运行，只是没有单词朗读；可在系统的「语音/语言」设置里添加英语语音包。
- 如果完全听不到声音，请检查系统音量、浏览器标签页是否被静音，以及是否已经点过页面。

## 七、错词记录与清理

- 游戏会把每个单词的「击中正确次数 / 击中错误次数」保存在浏览器的 `localStorage` 中，键名是 `wordBreakerStats`。
- 错词 = 历史上至少击中错误一次的单词；错词关按错误次数从多到少生成，最多 18 个。
- 错词不足 4 个时，开始页会显示「错词复习（暂无）」并给出提示。
- 错词统计只保存在当前浏览器的当前使用环境里，不会上传到网络；换浏览器或清除浏览器数据后会重新开始。
- 想清空错词记录，可以在浏览器开发者工具（F12）的 Console 里执行：

```js
localStorage.removeItem('wordBreakerStats');
```

然后刷新页面即可。所有存储操作都有异常保护，即使浏览器禁用了 `localStorage`，游戏也能正常玩。

## 八、常见问题

**双击打不开或页面空白？**
确认 `index.html`、`css/`、`js/` 三个部分都在同一个 `word-breaker` 文件夹内，没有被单独移动。

**修改词库后没生效？**
确认保存的是 `js/words-data.js`，并强制刷新页面（`Ctrl + F5`）。

**手机横屏时画布太小？**
游戏会自动选择横屏或竖屏逻辑分辨率并等比缩放；也可以直接用竖屏玩。

**没有声音/没有发音？**
见上面的「声音与单词发音」。无头或静音环境不会影响游戏逻辑。

**如何完全重置游戏数据？**
清除浏览器站点数据，或在 Console 执行上面的 `localStorage.removeItem(...)`。

## 九、给家长的说明

- 游戏的目标是让孩子在“找对应单词”的过程中反复认读，不追求高难度操作，因此错误的单词砖不会扣命。
- 目标选择会自动避开被完全包围、小球打不到的砖块，不会出现“怎么打都过不了”的死局。
- 建议先打开「慢速模式」，陪孩子读一遍预习闪卡，再开始玩。
- 错词复习关是一个轻量的复习工具，不宜一次玩太久；可以每天玩 5–10 分钟。
- 所有单词和难度都在本地文件中，按孩子的教材和节奏随时调整即可。
