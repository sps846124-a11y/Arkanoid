# 小又的打砖块游戏

给 6–9 岁孩子玩的英语单词学习小游戏：经典打砖块 + 单词匹配。

游戏支持两种双向学习模式：

- **中文找英文**（默认）：顶部显示中文和 emoji（例如「书店」），砖块上写英文单词（bookshop），单词砖按词性用不同颜色区分；
- **英文找中文**：顶部显示并朗读英文单词，砖块上写中文意思，所有砖块统一为浅蓝色。

开始页还可以选择难度：简单 1 排、普通 2 排、困难 3 排、地狱 4 排，每排最多 4 块砖；每关开局会从本关词库随机抽词。

整个游戏只用 HTML + CSS + JavaScript + Canvas，**没有任何外部库、图片、音频文件或网络请求**，可以直接离线玩。

---

## 一、如何打开

1. 找到 `word-breaker` 文件夹里的 `index.html`。
2. **双击 `index.html`**，用 Chrome 或 Edge 打开即可。
3. 不需要安装软件、不需要启动服务器、不需要联网。

第一次进入会先看到开始页：

- 选择 Unit 1～6；
- 选择出题模式：中文找英文（默认）或英文找中文；
- 选择难度：简单 / 普通（默认）/ 困难 / 地狱；
- 可打开「慢速模式」（小球速度降低约 30%，适合低龄孩子）；
- 点「开始游戏」后先看 8 秒预习闪卡，然后开始玩。

> 建议使用最新版 Chrome 或 Edge。手机、平板也可以用，支持横屏和竖屏。

## 二、基本玩法

- 鼠标拖动、手指拖动或键盘 `←` `→` 移动滑块。
- 点击画布、轻触画布或按空格发球。
- 中文找英文模式：先看画布顶部的中文目标和 emoji，再引导小球击中对应的英文单词砖。
- 英文找中文模式：看 / 听顶部朗读的英文单词，引导小球击中对应的中文砖块；击中正确砖时会再朗读一遍英文。
- 目标只会从最外层、小球能打到的砖块中随机选择；如果某个目标被其他砖块完全围住（小球不可能打到），系统会自动换一个可达的目标并更新顶部提示。切换横屏/竖屏后也会重新检查。
- 击中正确砖：砖块消除、加分、朗读英文单词，并自动换下一个目标。
- 击中错误砖：砖块温和地闪一下红色，不消除、不扣分、不扣命，但连击会清零。
- 漏球扣 1 条命；每关 3 条命，命用完可以重玩本关。
- 连续击中正确砖会积累连击；连击 ≥ 3 时小球会加速约 10%，并出现更明显的粒子和光环。
- 过关或失败后都会先复习本关单词，再显示得分和正确率。

```
word-breaker/
├── index.html            ← 双击这个文件开始玩
├── manifest.json         ← PWA 应用配置（名称、图标、截图）
├── service-worker.js     ← 离线缓存
├── icon-192.png          ← App 图标（192×192）
├── icon-512.png          ← App 图标（512×512）
├── screenshot-wide.png   ← 横屏展示截图
├── screenshot-narrow.png ← 竖屏展示截图
├── css/
│   └── style.css         ← 页面、按钮、闪卡、结算页样式
├── js/
│   ├── words-data.js     ← 词库（家长主要改这个文件）
│   ├── audio.js          ← 合成音效 + 单词朗读

```

请不要改动文件的相对位置和 `<script>` 引入顺序。

## 四、如何修改词库

打开 `js/words-data.js`，按下面的格式增删单词，保存后刷新浏览器即可生效，不需要改其他代码。

```js
const WORD_DATA = {
  unit1: {
    unit: 1,
    title: "Unit 1 · 运动与时间",
    words: [
      { word: "jump", zh: "跳", pos: "verb", emoji: "🦘", key: true },
      { word: "rope", zh: "绳", pos: "noun", emoji: "🪢" }
    ]
  },
  // unit2 ~ unit6 同结构
};
```

单词字段：

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| `word` | 必填 | 英文单词或短语 |
| `zh` | 必填 | 中文意思，会显示在目标卡片上 |
| `pos` | 必填 | 词性，只能填 `noun` / `verb` / `adj` / `other` |
| `emoji` | 可选 | 表情，没有就填空字符串 `""` |
| `key` | 可选 | 历史保留字段；当前版本按难度随机抽词，不再优先核心词 |

砖块颜色由 `pos` 决定：

- `noun` 名词 → 蓝色
- `verb` 动词 → 橙色
- `adj` 形容词 → 绿色
- `other` 其他 → 灰色

注意事项：

- 每关开局从本关词库**随机抽词**：简单 4 个、普通 8 个、困难 12 个、地狱 16 个；多玩几次可以覆盖全部单词。
- 词库单词不足所需数量时按实际数量铺砖，砖块整体居中；最少建议 4 个。
- 开始页的 Unit 卡片会显示当前难度下本关最多用几个单词。
- 中英文都可以用，但单词本身建议保持英文，否则朗读和认读效果不好。
- `word` 里可以带空格（如 `be good at`、`sports centre`），砖块会自动尝试拆成两行。
- 如果只修改了词库但页面没变化，请强制刷新（`Ctrl + F5`）或检查文件是否保存成功。

## 五、如何调整难度

游戏开始页可以直接选择「简单 / 普通 / 困难 / 地狱」。如果想改底层手感参数，打开 `js/main.js`，文件顶部有一个 `CONFIG` 对象，直接改数字即可。常用参数：

| 参数 | 默认值 | 作用 |
| --- | --- | --- |
| `START_LIVES` | `3` | 每关初始生命数 |
| `BALL_SPEED` | `430` | 小球基础速度（越大越快） |
| `SLOW_MODE_FACTOR` | `0.7` | 慢速模式速度倍率（0.7 ≈ 降低 30%） |
| `PADDLE_KEYBOARD_SPEED` | `760` | 键盘移动滑块的速度 |
| `PADDLE_HIT_PAD` | `18` | 滑块左右额外判定宽度，越大越容易接球 |
| `BRICKS_PER_ROW` | `4` | 每排砖块数；难度决定排数（1~4 排） |
| `PREVIEW_SECONDS` | `8` | 每关开始前预习闪卡的秒数 |
| `REVIEW_STEP_MS` | `1400` | 过关复习闪卡每个单词停留的毫秒数 |
| `BRICK_SCORE` | `10` | 击中一块目标砖的基础得分 |
| `COMBO_SCORE_STEP` | `2` | 连击每多 1 次额外加的分 |
| `COMBO_SCORE_MAX` | `20` | 连击加分上限 |
| `COMBO_SPEED_THRESHOLD` | `3` | 连击达到多少次开始加速 |
| `COMBO_SPEED_BONUS` | `0.1` | 连击加速幅度（0.1 ≈ 提升 10%） |
| `TARGET_SPEAK_START_DELAY_MS` | `250` | 模式 B 开局朗读目标单词的延迟（毫秒） |
| `TARGET_SPEAK_DELAY_MS` | `1300` | 模式 B 换目标后朗读新单词的延迟（毫秒） |
| `PARTICLE_COUNT` | `12` | 每次击中的粒子数量（低配设备可调小） |

例如想让孩子更容易上手：

```js
START_LIVES: 5,
BALL_SPEED: 360,
SLOW_MODE_FACTOR: 0.6,
```

改完后保存并刷新页面即可。

## 六、声音与单词发音

- 击中正确、击中错误、过关三种音效都用 Web Audio API 现场合成，不依赖音频文件。
- 英文单词用浏览器自带的 `speechSynthesis` 朗读，优先选择美式/英式英文语音，语速约 0.85。
- 浏览器要求先有一次用户点击或按键才能播放声音，所以请在开始页点按钮、或先点一下画布。
- 如果电脑没有安装英文语音，游戏仍然正常运行，只是没有单词朗读；可在系统的「语音/语言」设置里添加英语语音包。
- 如果完全听不到声音，请检查系统音量、浏览器标签页是否被静音，以及是否已经点过页面。

## 七、PWA 与打包成 App

本项目已经包含 PWA（可安装网页应用）所需的基础文件：

- `manifest.json`：应用名称、图标、截图、主题色等；
- `service-worker.js`：缓存游戏文件，断网也能打开；
- `icon-192.png` / `icon-512.png`：真实图片图标；
- `screenshot-wide.png` / `screenshot-narrow.png`：PWABuilder 展示截图。

打包成 APK 的推荐流程：

1. 把代码推送到 GitHub；
2. 在仓库 **Settings → Pages** 中启用 GitHub Pages（分支 `main`，目录 `/ (root)`）；
3. 用得到的 HTTPS 地址（例如 `https://用户名.github.io/Arkanoid/`）在 [PWABuilder](https://www.pwabuilder.com/) 中生成 Android 包；
4. 下载 APK / AAB。

**重要：更新游戏后请修改缓存版本。**
`service-worker.js` 顶部的 `CACHE_NAME` 现在是 `xiaoyou-brick-v3`。每次修改 HTML/CSS/JS/图片并推送后，把它改成 `v4`、`v5`……，否则已经安装过的浏览器可能继续使用旧缓存。

Service Worker 只在 `https://`（或本机开发服务器）下生效；直接双击 `index.html` 用 `file://` 打开时会自动跳过，不影响本地游玩。

## 八、常见问题

**双击打不开或页面空白？**
确认 `index.html`、`css/`、`js/` 三个部分都在同一个 `word-breaker` 文件夹内，没有被单独移动。

**修改词库后没生效？**
确认保存的是 `js/words-data.js`，并强制刷新页面（`Ctrl + F5`）。

**手机横屏时画布太小？**
游戏会自动选择横屏或竖屏逻辑分辨率并等比缩放；也可以直接用竖屏玩。

**没有声音/没有发音？**
见上面的「声音与单词发音」。无头或静音环境不会影响游戏逻辑。

**如何重新开始？**
刷新页面即可。游戏目前不会在浏览器里保存进度。

## 九、给家长的说明

- 游戏的目标是让孩子在“找对应单词”的过程中反复认读，不追求高难度操作，因此错误的单词砖不会扣命。
- 目标选择会自动避开被完全包围、小球打不到的砖块，不会出现“怎么打都过不了”的死局。
- 建议先打开「慢速模式」，陪孩子读一遍预习闪卡，再开始玩。
- 所有单词和难度都在本地文件中，按孩子的教材和节奏随时调整即可。
